# HTML 可视化编辑器

在浏览器中直接编辑本机 HTML 页面：改文字、调样式、拖动组件，并保存回原 HTML。适合静态网页、产品原型和演示页面，也能配合 AI 编程工具一起使用。

免费开源，采用 [MIT 许可证](LICENSE)。运行在你的电脑上，无需注册账号，无需安装运行依赖。

## 三步开始使用

1. 安装 [Node.js](https://nodejs.org/)，需要 **22 或更高版本**。
2. 点击仓库右上方 **Code → Download ZIP**，解压到电脑上。
3. 在解压后的文件夹中打开终端，运行：

   ```bash
   npm start
   ```

打开浏览器访问 **[http://127.0.0.1:4174/editor/editor.html](http://127.0.0.1:4174/editor/editor.html)**。使用期间保持终端窗口开着；按 Ctrl + C 停止服务。

**Mac 用户**也可在安装 Node.js 后双击 `快捷启动.command`。如果文件不可执行，可在终端运行 `chmod +x 快捷启动.command`，或直接使用上面的启动命令。

**Windows / Linux 用户**使用 `npm start`。Windows 可在文件夹地址栏输入 `cmd` 回车，再输入启动命令。

不需要运行 `npm install`。也可以用 `node dev-server.mjs --port 4174` 启动。

## 第一次体验

点击编辑器顶部的“打开项目文件夹”，选择仓库里的 **`examples/demo`** 文件夹，再切换到“编辑”模式，就能试着修改示例页面。

macOS 支持系统文件夹选择器；Windows / Linux 请在弹窗中粘贴文件夹的完整路径。

使用自己的页面时，选择包含 HTML、CSS、JS、图片等资源的项目根目录，然后在顶部“页面”菜单切换文件。更多操作见 [使用指南](EDITOR-QUICKSTART.md)。

## 可以做什么

- 点击选择元素，双击改文字；调整字体、颜色、圆角、透明度、尺寸和留白。
- 拖动、跨容器移动、对齐吸附；调整横向、纵向与网格排列。
- 新增文字、按钮、卡片、容器、矩形、圆形和本地图片；复制、删除、多选、隐藏与锁定。
- 撤销 / 重做，浏览器自动保存草稿。
- 保存回原 HTML，检查外部修改冲突，并自动备份源码。
- 预览历史版本、恢复源码、上下对比版本。
- 导出调整 JSON 或包含本地资源的项目 ZIP。

## 保存与分享

编辑时先自动保存到浏览器草稿；点击 **“保存到项目”** 才会写入你选择的原 HTML。写入前会检查冲突，并备份 HTML、项目 CSS/JS 和草稿。

普通静态项目可通过 **“导出项目 ZIP（含资源）”** 分享。接收者解压后用本地 HTTP 服务打开；远程资源和后端接口仍需自行提供。分享多页面项目之前，请逐页保存希望包含的改动。

编辑器自身需要本地 Node.js 服务来读取和保存文件。GitHub 仓库用于下载和分享，不能通过 GitHub Pages 完整运行这个编辑器。

## 支持范围

支持普通静态 HTML 项目。React / Vue 等需要构建的源码项目，请先生成静态页面。运行时脚本生成、无法对应到源码的组件暂不支持反向保存，可保留草稿或修改其生成逻辑。复制组件不会复制通过 JavaScript 绑定的事件。

服务默认只监听 `127.0.0.1`，用于本机编辑。浏览器里的被编辑页面仍会运行自身脚本，请选择你信任的项目。

本机配置 `editor-config.json`、最近项目路径、编辑记录和历史备份都已加入 Git 忽略规则。

## 开发与测试

```bash
npm test
```

测试使用 Node.js 自带的测试工具，不需要安装依赖。可选的浏览器集成测试需要 Playwright：

```bash
npm ci
npx playwright install chromium
npm run test:browser
```

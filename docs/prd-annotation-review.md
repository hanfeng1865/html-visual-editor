# AI 标注审核流程

点击「AI 分区与标注」先进行本地 DOM 扫描，不调用模型。右侧审核栏支持名称修改、合并、拆分、删除和框选添加，不遮挡主页面。页面同步显示区块编号和范围，悬停列表项高亮，点击编号滚动定位。确认后保存分区，再请求模型；模型失败时，分区和原说明仍保留。

穿透页按容器、页面标题和表头组合识别独立视图。同一抽屉显示不同明细时，分别保存区块和说明；审核侧栏随当前视图切换，返回主页面保留本次手改。关闭抽屉中的占位元素不扫描，范围框裁剪到抽屉及滚动容器内。已有未记录视图身份的穿透页说明不会直接套到新内容上，需要重新审核分区。

数据采用 version 2：`blocks` 保存稳定 ID、选择器、标题/路径/内容结构指纹和子项；`points` 通过 blockId 关联区块，保存类型、来源、状态、子项及可选修改建议。全局规则最多一条。旧标注迁移前保留在 archivedPoints；能按区块及子项定位的旧说明迁入新区块，未能定位的旧记录仍保存在归档字段。

侧栏支持概览/详细、悬停高亮、单条和批量接受、删除、手动补充及修改建议的接受/拒绝。审核状态通过黄色「待确认」、绿色「已确认」和「已过期」标签展示，每条区块说明和子项分别确认。批量确认只确认当前视图的区块草稿，不代替子项审核。编辑表单可选择确认状态，修改文字不会自动确认。依据使用「页面可见 / 结构推断 / 尚未核实」，与审核状态分开。正文中的待确认事项需人工核实并修改，确认按钮不改写正文。分区调整统一从审核侧栏进入。编号依据当前页面全部区块的阅读顺序统一分配，页面和侧栏保持对应，滚动或按类型筛选时不重新编号，固定在所属区块的左上角，避让仅在该角附近调整，不移到右侧或下沿；没有安全位置时保留侧栏条目，不强行压住页面内容。

重跑按指纹检测变化。未变化且已分析的区块不再调用模型；变化的标为已过期，新说明作为建议保留，旧说明不被覆盖。消失的区块保留为已过期。删除的分区选择器记录在 ignoredSelectors。保存保留修订冲突检测。

生成时会将当前预览的 DOM、计算样式和 Canvas 快照通过 gzip 压缩传到后台，还原后在隔离浏览器中渲染成截图，与分区树一起发给已配置模型。截图禁止脚本及外部网络请求；跨域图片、外部字体、伪元素和部分动态媒体可能与原页面不同。隐藏面板通过分区树传递，截图只反映当前视口。需要安装 Playwright Chromium（与项目浏览器测试相同的依赖）。

验证：`npm test` 和 `npm run test:prd`。生成链路使用模拟模型验证协议、截图传递、状态和保存行为，不代表真实模型的说明准确率。

需求与标注双向提供依据：迭代分析和问题生成会读取关联页面已保存的 PRD 说明，包括区块、子项、审核状态、来源及所属迭代；页面修改备注与 PRD 标注分别传入模型。仅已确认说明中的明确规则作为依据，仍待核实部分和草稿/已过期内容保留为线索，不把父区块确认视为子项确认。标注生成读取关联迭代文档及已保存回答，本轮明确回答优先于旧文档，冲突提出修改建议。文档或回答变化会使标注分析缓存失效，重新核对未缺失区块；只产生建议，不自动覆盖已有正文或审核状态。同标题子项的建议独立接受或拒绝。侧栏「根据需求更新说明」可以直接核对已确认分区，无需重新分区。双向读取以落盘数据为准，未保存草稿不传入另一流程；不会因点击审核确认就自动将业务问题视为已回答。

分区审核默认仅展示当前显示的区块（包含可滚动到的区块，不混入隐藏 Tab）。其他 Tab / 未显示分区保留在折叠列表并标明所属区域，切换后动态更新当前列表和编号范围；手动修改与隐藏分区不会丢失。每行提供显式定位按钮，滚动并高亮对应范围。

标注扫描提供控件实际属性作为依据（导航目标、当前选中/当前页面、必填和禁用），截图渲染时再次读取以兼容旧分区。可直接读出的导航和控件事实不转成需要用户补充 URL 的问题。当前选中的导航被错误写为链接待确认时，生成链路会校正该说明；品牌纯展示不当作可点击入口。旧说明通过更新建议保留，人工内容不自动覆盖。

点击单个角标进入精简视图，仅保留该条说明、返回列表和编辑操作；批量确认、补充说明及更新入口在完整列表展示。依据与审核信息默认折叠，子项不会因上次详细模式而自动展开。普通 CTA 的跳转与导航目标一致时，直接生成一句交互说明，剔除静态宣传文案和重复 AI 子项；代码可确定的跳转不要求用户补目标地址。人工说明和人工子项保留。截图请求另带原页面读取的控件属性，避免安全快照移除 onclick 后丢失确定的跳转信息。

标注界面不展示交互/字段/规则/边界/全局分类标签、分类筛选或编辑分类下拉框。列表按页面阅读顺序排列，角标统一样式，仅保留说明和审核状态。已有类型字段保留兼容存储，编辑说明不会改动该字段。

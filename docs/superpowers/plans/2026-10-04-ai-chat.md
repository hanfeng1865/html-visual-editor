# 自然语言修改源码实施计划

**目标：** 增加 AI 对话入口，使用已有模型连接修改当前项目，并固定加入编辑器兼容规则。
**架构：** 扩展已有生成接口，接收自然语言 request 与有界对话 history；复用精确源码替换、预览、错误基线、备份和确认写入。前端先保存普通草稿，再生成，按页面保留对话记录。
**技术：** 静态 HTML/CSS、原生 JavaScript、Node.js 22、现有 Playwright 测试。

- [x] 服务测试：无待办时自然语言生成，指令包含全部兼容规则；确认前不写入、确认后保存、历史变化拒绝写入；拒绝空请求、超长请求及无效历史。
- [x] 服务实现：ai-source-rules.mjs 导出固定规则；ai-service.mjs 的 generate(project,{request,history}) 验证输入并加入 task；dev-server.mjs 转发请求体。
- [x] 浏览器测试：自然语言发送、预览确认、多轮修改、普通草稿先保存、失败保留输入和对话、生成后更改输入使旧结果不能写入、刷新后恢复对话。
- [x] UI 实现：左侧工具栏 AI 对话入口，右侧非模态侧栏内输入框、发送按钮、记录；复用 generateAI 与 apply；生成请求携带 request/history，禁止并发；保存普通草稿时关闭自动生成以免重复请求。
- [x] 验证：重复 ID 检查区分已有问题和新增问题；保留现有待办效果验证与源码冲突检测。执行 npm test、npm run test:browser 和新增 AI 对话浏览器测试。
- [x] 文档：使用说明和使用指南说明入口、兼容要求、预览确认与历史记录的边界。

# Diagrams Implementation Plan

> **For agentic workers:** Use subagent-driven-development to implement and review task-by-task.

**Goal:** 交付图解组件和独立业务逻辑说明页，共用 AI 生成能力。

**Architecture:** diagram-service.mjs 管理上下文、候选、校验和独立文件保存；diagram-ui.mjs 管理弹窗，editor.js 通过回调接入现有组件插入与撤销链路。采用上游固定版本规范和按类型参考。

**Tech Stack:** Node.js、原生浏览器模块、HTML/SVG、Playwright。

## Global Constraints
- 保留当前工作区已有修改，不覆盖其他功能。
- 默认静态 HTML/SVG、中文系统字体，无外部字体依赖。
- 生成只产生候选，采用后才插入/保存。
- 失败保留旧候选与源码；新说明页不覆盖现有文件。

## Task 1: 生成服务与规范
- [x] 新建 diagram-service.mjs、生成 Skill 和四种类型参考，扩展 generation-skills.mjs 与 dev-server.mjs。
- [x] 暴露 POST /api/diagrams/generate 和 /api/diagrams/save。生成输入 mode/type/request/current/context，输出 id/title/html/component；保存输入 id，输出 entry/url。
- [x] 读取相关源码、逻辑说明、已确认需求；严格验证输出，唯一化 ID，检查越界；候选绑定项目，保存使用 wx。
- [x] tests/diagram-service.test.mjs 验证正常生成、非法代码、项目隔离、无覆盖保存。

## Task 2: 编辑体验
- [x] 新建 diagram-ui.mjs 和 diagram.css；editor.html/editor.js 接入顶部、组件面板、选中图解、逻辑说明入口。
